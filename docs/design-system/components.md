# Component Specifications & Guidelines

## Core Primitives (`@sirius/ui`)

- **Button**: `Button`, `GradientButton`, `GhostButton`, `IconButton`
- **Form Controls**: `Input`, `TextArea`, `Select`, `Checkbox`, `Switch`
- **Data Display**: `Badge`, `Pill`, `Tooltip`, `Card`, `GlassCard`, `GlassPanel`, `Avatar`
- **Feedback**: `ProgressBar`, `Spinner`, `Skeleton`, `ToastContainer`
- **Navigation & Overlays**: `Tabs`, `Dropdown`, `Modal`, `GlassModal`, `Drawer`

## SIRIUS-Specific Components

- **`SeverityChip`**: Displays severity glyph and label. Critical variant features violet glow.
- **`ScoreRing`**: Circular SVG progress arc with animated count-up number.
- **`MoneyTicker`**: Tabular numeral financial ticker with count-up animation and currency formatting.
- **`StatusPulse`**: Real-time status indicator dot with animated pulse ring.
